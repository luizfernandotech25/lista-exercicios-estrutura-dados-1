
# Exercício 09 — Soma Recursiva de uma Lista

**Disciplina:** Estrutura de Dados I  
**Curso:** Tecnologia em Sistemas para Internet  
**Instituição:** IF Goiano  
**Linguagem:** Java  
**IDE:** Apache NetBeans 31

## Objetivo

Implementar uma função recursiva que recebe uma lista de números inteiros e retorna a soma de seus elementos.

## Implementação

Foi desenvolvida a classe `Exercicio_09`, responsável pela leitura dos números, armazenamento em uma lista e execução da soma recursiva.

## Estratégia utilizada

A solução utiliza recursividade para percorrer a lista.

- **Caso base:** quando o índice alcança o tamanho da lista, retorna zero.
- **Caso recursivo:** soma o elemento atual ao resultado da chamada seguinte.

## Tecnologias

- Java
- Maven
- Apache NetBeans 31

## Testes

- Lista com números positivos.
- Lista com números negativos.
- Lista com valores positivos e negativos.
- Lista vazia.

## Execução

Executar a classe `Exercicio_09`.
