
# Exercício 01 — Pilha

**Disciplina:** Estrutura de Dados I  
**Curso:** Tecnologia em Sistemas para Internet  
**Instituição:** IF Goiano

## Objetivo

Desenvolver um programa em Java que utilize a estrutura de dados Pilha para:

1. Ler uma sequência de caracteres de tamanho indeterminado.
2. Imprimir a sequência na ordem inversa.
3. Verificar se a sequência é um palíndromo, desconsiderando espaços e pontos.

## Implementação

Foi desenvolvida uma classe genérica `Pilha<T>`, com as operações:

- `push()`: insere um elemento no topo da pilha.
- `pop()`: remove e retorna o elemento do topo.
- `isEmpty()`: verifica se a pilha está vazia.

## Tecnologias

- Java 17
- Maven
- Apache NetBeans

## Execução

Executar a classe `Exercicio01`.

## Observação

A verificação do palíndromo ignora espaços, pontos e diferenças entre letras maiúsculas e minúsculas.
